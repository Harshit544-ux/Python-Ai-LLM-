# Python-Ai-LLM

This repository contains a collection of Python programming examples and tutorials aimed at beginners. Each file demonstrates a specific concept in Python programming language.

## Files

- `dataType.py`: Covers Python data types including integers, floats, booleans, strings, complex numbers, lists, tuples, dictionaries, sets, type checking, variables, dynamic typing, user input, type conversion, strings, literals, and None.
- `operator.py`: Explains various operators in Python: arithmetic, relational, logical, bitwise, assignment, and membership operators. Includes examples and a small program to sum three numbers.
- `print.py`: Demonstrates the usage of the `print()` function, including printing different data types, separators, and end parameters.
- `ifElse.py`: Contains commented-out examples of conditional statements (if, elif, else), including a login program, finding the minimum of three numbers, a menu-driven program, and importing Python modules (math, random, keyword, datetime). The code is commented for educational purposes.
- `function.py`: A placeholder for Python function examples (currently empty).
- `opps.py`: Demonstrates Object-Oriented Programming (OOP) concepts like classes, objects, parameterized constructors, multiple objects with unique data, and encapsulation using private variables. Includes an ATM simulation example.

## How to Use

Each file can be run independently using Python 3:

```bash
python3 dataType.py
python3 operator.py
# etc.
```

Feel free to modify the code, uncomment sections in `ifElse.py`, and experiment.

## Purpose

The goal of this repository is to provide clear, concise examples for learning Python fundamentals. It is suitable for self-study or as a supplement to a beginner's Python course.
